# Original unseeded experiments

[`original_unseeded/`](original_unseeded/readme.md) is a byte-for-byte snapshot of all 25 tracked files from [GitHub commit `0294880997046b3a8352796b7ce58a2d27717b63`](https://github.com/zyberg2091/trm-halting-targets/tree/0294880997046b3a8352796b7ce58a2d27717b63), dated August 25, 2026.

It contains the three original 4-digit notebooks, their 15 run summaries and three CSV tables, the original README and report, and the notebook/log directory READMEs. Its relative directory layout and file contents are unchanged. It contains no Git metadata.

The original report records the earlier interpretation. Use the [revised report](../docs/technical_report.md) for corrected interpretations of those results and the [seeded follow-up report](../docs/seeded_results.md) for the newer experiments. The original code includes the documented halt-loss masking issue; the seeded code corrects it.

The current log extractor intentionally operates only on the newer notebooks and logs at the repository root.
